# csacr
Android code recommendation



The SO-android-question.xlsx file collects the curated questions.

The crawler_from_android_website.zip contains the code to generate evolution api knowledge info

The mined_api_knowledge_base.zip contains the json dataset which are mined from android offical website through the
crawler_from_android_website.zip code.

Android Evolution Dataset: https://zenodo.org/records/24340490
Non-Evolution Android dataset： https://github.com/JohnnyPeng18/APIBench
